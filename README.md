# git

一个用来**学习 Git 版本控制**的练习仓库。

仓库由本地初始化并推送到 GitHub，内容是一份自学指南和练习场地。

## 从这里开始

- 📘 [GIT-学习指南.md](GIT-学习指南.md) —— 核心概念、日常操作、撤销技巧、分支，以及 10 个可反复练的练习
- ✍️ [练习记录.md](练习记录.md) —— 每完成一个练习在这里记一行，顺便练习提交

## 快速开始

```bash
git status      # 看当前改了什么
git add .       # 放进暂存区
git commit -m "描述改动"   # 提交
git push        # 同步到 GitHub
```
